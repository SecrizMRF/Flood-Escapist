### ?? What is this Project ??
Projek ini adalah Game yang Tim kami bangun menggunakan Game engine Unity.
Game yang kami angkat ini berjudul Flood Escapist, berlatar belakang di kota yang krisis karena dilanda banjir.
Player harus survive dari terjangan banjir setelah terjebak di dalam gedung.
### Tech Stack
1. Unity
2. C#
3. Libresprite
4. AI Companion

### How to Run the Game?
1. Download Build game berekstensi .zip (tersedia versi 0.4.1 dan 0.4.2. Basically identik, no significant difference)
2. Ekstrak .zip
3. Run file Flood Escapist.exe
4. Jika ada pop up windows protector, pilih more info -> run anyway

### OOP Implementation
1. Encapsulation -> kami menerapkan ini pada Method dan Variable sensitif untuk melindungi isinya
2. Inheritance -> kami menerapkan ini pada sisi Obstacle yang digunakan, dimana ada 2 obstacle berbeda, namun memiliki peran yang sama
3. Polymorphism -> kami menerapkan ini pada keragamana sifat dari Obstacle kami
4. Abstraction -> kami menerapkan ini di beberapa hal, salah satunya di parent class obstacle terhadap Children nya
