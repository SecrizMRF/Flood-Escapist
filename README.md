### ?? What is this Project ??
Projek ini adalah Game yang Tim kami bangun menggunakan Game engine Unity.
Game yang kami angkat ini berjudul Flood Escapist, berlatar belakang di kota yang krisis karena dilanda banjir.
Player harus survive dari terjangan banjir setelah terjebak di dalam gedung.
### Tech Stack
1. Unity
2. C#
3. Libresprite
4. AI Companion
